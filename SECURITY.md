# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly.

**Do not** open a public GitHub issue for security vulnerabilities. Instead:

1. Email security@treeo.com with:
   - Description of the vulnerability
   - Steps to reproduce
   - Potential impact
   - Your contact information

2. Allow reasonable time (typically 90 days) for a fix before public disclosure
3. We'll acknowledge receipt and keep you updated on progress

## Supported Versions

Security updates will be provided for:
- Latest major version
- Previous major version (for critical issues only)

| Version | Supported |
|---------|-----------|
| Latest  | ✅        |
| Previous| ⚠️ Critical only |
| Older   | ❌        |

## Security Best Practices

When using this project:
- Keep dependencies up to date
- Review security advisories regularly
- Report vulnerabilities responsibly
- Use the latest stable version

Thank you for helping keep this project secure!
